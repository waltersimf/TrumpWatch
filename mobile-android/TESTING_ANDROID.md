# Перевірка TrumpWatch Android 1.0.2

## Що вже реалізовано

Головний екран є тонкою Android WebView-оболонкою над production-версією
TrumpWatch. У ньому мають відображатися ті самі англомовні секції, порядок,
стилі та responsive layout, що й у `client/` на еквівалентній ширині viewport.

Нативними залишаються локальний cache для віджетів, фонова синхронізація з
мінімальним інтервалом 15 хвилин та два системні віджети:
**TrumpWatch: відлік** і **TrumpWatch: економіка**. Задокументовані platform
відмінності наведено у `WEB_PARITY.md`.

## Створення інсталяційного APK у хмарі

Системні віджети потребують нативного Android-збирання; вони не працюють у браузері або в Expo Go. Для створення тестового APK виконайте у корені проєкту:

```sh
npx eas-cli@latest build --platform android --profile preview
```

Під час першого запуску сервіс попросить увійти до Expo-облікового запису та підтвердити створення Android-ідентифікатора. Після завершення він надасть посилання на APK; відкрийте його на планшеті та встановіть файл.

## Перевірка застосунку

Порівняйте головний екран із production web на тій самій ширині телефона або
планшета. Мова, labels, порядок countdown → ліва колонка → news, усі картки,
цитата, API status, notifications і mobile breakpoints мають збігатися з web.
Перевірте Android Back усередині web history, повторне завантаження після
network error і відкриття зовнішнього news/source URL у системному браузері.

Вимкніть мережу після успішного запуску та окремо перевірте, що раніше
синхронізовані дані залишаються доступними у двох home-screen widgets. Головний
WebView без мережі показує короткий native retry state і не дублює web dashboard.

## Перевірка віджетів

На головному екрані планшета натисніть і утримуйте порожню ділянку, відкрийте меню **«Віджети»**, знайдіть **TrumpWatch** та додайте обидва віджети. Натискання на кожен із них має відкривати застосунок. Оновлення віджетів може бути відкладене Android для економії батареї; система не гарантує точний час виконання фонового завдання.

## Технічна перевірка

Перед хмарним збиранням виконайте Android TypeScript check, Android Vitest,
production JavaScript export та Expo configuration validation. Фінальний parity
check потребує preview APK і фізичного телефона/планшета з актуальним Android
System WebView.
